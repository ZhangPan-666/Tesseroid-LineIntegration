# GitHub 发布包审阅记录

整理日期：2026-10-18。版本：0.1.0-rc.1。

## 方法与目录审阅结论

原目录共 259 个文件，包含生产 C++ 核心、MPI/OpenMP/串行入口、MATLAB MEX、核函数研究、论文实验、统计表、论文初稿和参考推导。原文件清单及 SHA-256 已写入 `SOURCE_INVENTORY.csv`。对代码、论文方法和实验说明的检查集中在算法路径、单位、接口、构建依赖、结果来源及复现入口；二进制数组按结构与哈希核对，不逐元素宣称完成科学审查。

普通 TLI：通过规范场的旋度修正，使球面通量成为常量；解析消去径向积分，形成两组成对边界线积分；使用笛卡尔 Taylor jet 计算三阶以内导数。投影裂分与聚点后使用自适应 GK15/GK21。

TLI-MMSI：近场采用均匀中心单元和边界聚合，远场采用二维径向约化核。它包含源重建与插值近似，不能把普通 TLI 的精确恒等式直接当作整个非均匀壳模型的精确性证明。源码还保留一些历史内部辅助路径；发布文档以当前公开 `point_estimate` 的调用路径为准。

## 已发现的科学复现限制

1. 原球壳说明写的是旧 GL6 远场线积分，当前源码为远场二维积分；现有全量结果缺少与当前源码一一对应的版本记录。本包保留原始数据，明确标注为归档结果。
2. 极轴解析函数不在所给目录内；两套全球基准的外部 ETOPO/VIM 源模型、重采样来源与地图资源也不齐全。依赖已列在 `REPRODUCIBILITY.md`，未随意补入来源或授权不明的材料。
3. 普通 API 默认 SI G，而 MATLAB/Work/壳接口使用 G=1；原说明“角度都是度”不适用于直接 C++ API。
4. MATLAB/Work 与 canonical C++ 的分量既有别名又有换序，现已列出逐位置对应表。`P` 包装是 MEX OpenMP，原总说明中的 `parfor` 表述不准确。
5. 壳远场目前未向公共接口传递 `Integral2Info` 的预算/收敛告警；磁场和旧 Work 接口也不提供全部误差状态。请求更严容差并不保证全部核已收敛。
6. 普通核心的上径向面使用外侧 Richardson 极限；下径向面、侧面、棱角的未定义值会被拒绝。精确极点有专用数值分支。近边界和非均匀壳模型仍需要更全面的独立分量验证。
7. 旧批处理驱动假设参数文件有效，部分读取/失败退出处理较弱；新用户集成优先使用直接 API 或 MEX。此次未重写数值核心和全部旧文件 I/O。
