# 径向链积分核峰位实验报告

## 目的

检验 `V`、`Vz`、`Vzz`、`Vzzz` 的边界线积分核是否必须采用通用
`peakfind`，以及峰值中心能否由计算点在球面边界上的几何投影直接确定。

## 几何峰位

对定纬边（参数为经度），最近点为

`lambda_star = wrap_and_clamp(Lambda)`。

对定经边（参数为纬度），球面最近点为

`phi_star = atan2(sin(Phi), cos(Phi) * cos(lambda_b - Lambda))`，

然后截断到该边的纬度区间。该公式已经由
`C++Codes/_TLI_estimate.h::geometric_projection` 实现。

Fukushima (2018) 的条件裂解是在其嵌套经纬积分变量的零点
`lambda = Lambda`、`phi = Phi` 处进行。它与当前边界线积分表示的定纬边
投影一致；对定经边，严格的球面最近点应采用上面的 `atan2` 公式。测试范围内
（经度间隔不超过 0.1 度），两者最大差约 `4.35e-5` 度。

参考：T. Fukushima (2018), *Accurate computation of gravitational field of a
tesseroid*, Journal of Geodesy, DOI: 10.1007/s00190-018-1126-2.

## 实验

新增两个只用于诊断的 C++ 程序：

- `peak_location_study.cpp`：0.1 度和 20 度单元；定纬边、定经边；单边界核和
  成对边界核；改变高度、边界间距和沿边位置，比较全局最大值与几何投影点。
- `radial_peak_profiles.cpp`：对 0.1 度单元进行投影点附近的核宽归一化高密度
  扫描，统计有符号极值和绝对值极值。

原始结果为：

- `results/peak_location_study.csv`（576 组）；
- `results/radial_peak_profiles.csv`（64 组）。

## 主要结果

1. 在数值稳定的测试范围（角间距不小于 `1e-3` 度）内，全部 48 组径向链
   剖面均只有一个显著的绝对值局部峰。
2. `Vzz` 和 `Vzzz` 的尖锐局部结构几乎总以几何投影点为中心。少数较远、
   较平缓的 `V`、`Vz` 剖面，其全局最大值偏移约 0.3--0.4 个核宽；这些情形
   不属于可能被积分节点漏掉的窄峰。
3. 在高度 1 m、角间距 `1e-6` 度的极端近场中，`Vzzz` 的绝对值最大点位于
   几何中心外约 0.75 个核宽（定经边）或 0.92 个核宽（定纬边）。这是高阶
   导数在中心两侧形成导数瓣的表现，不意味着应把裂解中心从几何投影点移到
   某一个瓣峰。
4. 同一极端构型下，`V`、`Vz`、`Vzz` 的双精度核评价出现大量很小的局部
   抖动。基于少量均匀样本、绝对值局部极大值和黄金搜索的通用 `peakfind`
   会把这些抖动当成峰；其峰数在这种区域没有物理意义。

## 对当前代码的判断

径向链不应采用通用 `peakfind` 决定裂解位置。应直接使用可解析的几何投影点
作为保护性裂解点，并由最短角距离与径向间距估计核宽。投影点是近奇异结构
的几何中心，不要求它恰好等于每个高阶核的绝对值最大点。

普通 TLI 和 TLI-MMSI 的生产代码现已统一为解析几何投影裂解。旧的
`find_symmetric_peaks`、`find_peaks`、侧峰镜像、黄金搜索和半峰宽估计均已从
生产头文件删除；本目录中的寻峰实现只用于离线核函数研究，不被正式程序引用。

MMSI 聚合核需要再作一层区分：所有定纬近场边界的投影经度相同；不同定经
边界的投影纬度略有差异，会形成一个很窄的峰中心簇。若后续需要增强默认
方法，应由各边界的解析投影确定中心簇范围，而不是对聚合函数做通用盲搜；
同时不能为每条边界都建立独立积分段，否则会重新引入本次聚合优化要消除的
复杂度。

## 建议

1. 所有 20 个分量保留“几何投影裂解”的统一原则。
2. 通用 `peakfind` 仅作为本目录的离线诊断工具，不能进入生产积分路径。
3. 后续实验可直接扫描 0.1 度 MMSI 近场聚合核，比较单一投影中心、解析投影
   中心簇和现有 panel 策略的误差与评价次数，再决定是否修改生产路径。
