# Runtime statistical audit outputs

These files are generated by `../Analyze_RuntimeTest1.m` from the archived
160,801-point benchmark CSV. Do not edit the generated CSV or LaTeX tables
manually.

- `runtime_audit.log`: complete console report used to verify Section 4.1;
- `runtime_component_statistics.csv`: minimum, maximum, mean, P50, P90, and
  P99 for every gravitational quantity;
- `runtime_rank_region_statistics.csv`: derivative-rank and cumulative
  statistics for all points and for points inside/outside the angular source
  projection;
- `runtime_statistics_tables.tex`: Supplementary Tables generated from the
  same statistics.
